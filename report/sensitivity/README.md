# Reviewer sensitivity tables

These files are generated by `reproduction/reviewer_sensitivity.py` from saved
evidence only. No estimator, preprocessing pipeline, dataset download or
Jacobian measurement is performed.

Run `python reproduction/reviewer_sensitivity.py --jacobian <matched.csv>
--contrasts <dataset_level_contrasts.csv> --output-dir report/sensitivity
--bootstrap-reps 10000`.

The independent unit for Jacobian association summaries is the dataset; the
bootstrap resamples dataset-specific estimates with seed `20261124`.
The matched table contains 19,856 mapping units from nine datasets, despite
earlier audit prose referring to ten. No denominator-level or protected-
division event records are present, so those analyses are unavailable.

Provenance comparison is `NOT_COMPUTABLE_FROM_PUBLISHED_AGGREGATES` because
there is no balanced provenance-stratified dataset-level contrast table.
`ADDITIONAL FIGURES REQUIRED: NO`.
